# Session Records

Session records are task history. They are not requirements, rules, or current
truth.

Suggested filename:

```text
YYYY-MM-DD-topic.md
```

Suggested content:

- task goal;
- relevant inputs and their authority;
- key conclusions;
- files changed;
- verification evidence;
- unresolved questions;
- rules or decisions affected.

At task end, distill durable conclusions into
`MEMORY/05-state/current.md`, an active rule, or a decision record.
