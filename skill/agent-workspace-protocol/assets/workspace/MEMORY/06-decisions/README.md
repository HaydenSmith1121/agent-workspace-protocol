# Decision Records

Use this directory for durable process, architecture, naming, and structure
decisions.

Suggested filename:

```text
NNNN-short-decision-title.md
```

Suggested sections:

- status and date;
- context;
- considered options;
- decision;
- consequences;
- verification or review trigger.

Decision records are not a log of every task. Use `03-sessions/` for history
and `05-state/` for current conclusions.
