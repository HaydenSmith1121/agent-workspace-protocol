# 决策记录

本目录用于长期流程、架构、命名和结构决策。

建议文件名：

```text
NNNN-short-decision-title.md
```

建议章节：

- 状态和日期；
- 背景；
- 考虑过的选项；
- 决策；
- 后果；
- 验证或复核触发条件。

决策记录不是每个任务的日志。任务历史放在 `03-sessions/`，当前结论放在 `05-state/`。
