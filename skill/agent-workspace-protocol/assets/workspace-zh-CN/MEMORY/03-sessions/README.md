# 会话记录

会话记录是任务历史，不是要求、规则或当前事实。

建议文件名：

```text
YYYY-MM-DD-topic.md
```

建议内容：

- 任务目标；
- 相关输入及其权威性；
- 关键结论；
- 修改的文件；
- 验证证据；
- 未解决问题；
- 受影响的规则或决策。

任务结束时，将长期结论提炼到 `MEMORY/05-state/current.md`、有效规则或决策记录。
